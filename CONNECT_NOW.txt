ClankerSpanker — connect a client
=================================

1) Start the host (on the machine with your code):
   cd host && npm run build && npm start
   # or: ./scripts/install-service.sh

2) Open setup on that machine (or from phone on same LAN/Tailscale):
   http://<host-ip>:8787/setup

3) Clients:
   - Browser UI:  http://<host-ip>:8787/app/
   - iOS app: paste Host URL + token from /setup
     Project: ios/GrokDispatch/ClankerSpanker.xcodeproj
     Bundle:  com.nightmoose.clankerspanker

Do not expose port 8787 on the public internet.
